CHANGELOG
=========

v1.1.0
------
- Add a private Attendance Follow-up worklist tied to low-attendance and
  no-record cases.
- Add owner, status, due-date and resolution workflows with append-only
  coordination notes and an audit timeline.
- Restrict case access to current form-group tutors and all-student staff.
- Retain cases until the source school year end plus 12 months, with an
  administrator-only audited retention purge.
- Add formula-safe CSV export scoped to cases the current manager can access.
- Recheck current case access under a row lock before appending coordination
  notes, and reject follow-up creation for students who are no longer active.
- Align follow-up audit event inserts with the installed actor column so case
  creation, updates, note events and export audit records persist correctly.
- Use Gibbon's standard Button component for attendance detail controls.

v1.0.5
------
- Preserve attendance calendar, rate and legend colors when printing.

v1.0.4
------
- Separate no-record student-days into a data-quality queue instead of treating
  them as low attendance.
- Respect student enrolment dates when calculating expected and no-record days.
- Show attendance definitions consistently in the report and CSV export.
- Persist an explicit per-user alert threshold without changing preferences on
  GET, print or CSV requests.

v1.0.3
------
- Make attendance type keyword groups configurable alongside their score weights.
- Support comma- or semicolon-separated aliases for multilingual attendance data.

v1.0.2
------
- Move course-history attendance score weights into database-backed settings.
- Add an administrator settings screen linked from the attendance report.

v1.0.1
------
- Add CSV export for the full attendance history by course.
- Reject relative or malformed date inputs and fall back to the safe default range.
- Require transfer schedule rows to match the submitted source and target classes.
- Expand English attendance-score matching.

v1.0.0
------
- Added school-wide analytics, alerts, CSV export and print views.
- Added full attendance history by school day and by course.
- Added role-aware attendance transfer with CSRF, class/student validation,
  transactions and an audit table.
- Added English source strings and Simplified Chinese translations.
- Added regression tests for scoring and CSV formula protection.
